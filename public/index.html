The app

The first complete FTO solver.

FTO Alg Finder is a desktop solver to help you gen the ideal FTO algs.
Think Cube Explorer but for FTO: we support graphical input, partial pieces, alg to set state, restricted movesets, last-layer mode, and center disambiguation.

input

See the state

Set sticker colors manually, swap pieces, or set a piece to be a wildcard. Everything is graphical and from the viewer.

search

Control the moveset

Run solves while restricting what moves the solver can use. Specify whether you want solutions at a specific move count, or just the optimal depth.

modes

Separate the centers

In LL mode, you can mark a center as belonging in the top layer or otherwise. You can also control which slot a specific center should go to.

prerequisites

System prerequisites

Minimum practical setup

  • 64-bit Windows or Linux desktop.
  • 8 GiB RAM for shallow and moderate searches.
  • At least 1.2 GiB available RAM for pruning and transition tables.
  • 2 GiB free disk space for dependencies, builds, and normal caches.

Recommended for heavier use

  • 5-10 GiB free disk space for several solver instances or pruning caches.
  • Multiple CPU cores when using the thread setting.
  • Rust Edition 2024 toolchain, Node.js 18+, and npm when building from source.
  • More memory for deep exact-depth CLI searches.
