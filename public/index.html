The app

The first complete FTO solver.

FTO Alg Finder is a desktop solver to help you gen the ideal FTO algs.
Think Cube Explorer but for FTO: we support graphical input, partial pieces, alg to set state, restricted movesets, last-layer mode, and center disambiguation.

input

See the puzzle

Set sticker colors manually, swap pieces, or set a piece to be a wildcard to set up a partial position. Everything is graphical and from the viewer.

search

Control the moveset

Run solves while restricting what moves the solver can use. Specify whether you want solutions at a specific move count, or just the optimal depth.

modes

AUF-Neutral LL algs

In Last Layer mode, you can mark a center as belonging in the top layer or otherwise. You can also control which slot a specific center should go to.

Requirements

System Requirements

Minimum practical setup

  • 64-bit Windows or Linux desktop.
  • 8 GiB total RAM with at least 1.2 Gib available, ready to go.
  • 2 GiB free disk space for pre-generated tables of one solver instance.

Recommended for heavier use

  • 5-10 GiB free disk space for several solver instances and pruning tables.
  • Multiple CPU cores when using the thread setting.
  • 16 GiB ram for multitasking while the app has pruning tables loaded.
