The idea

For FTO solvers who care about the moves, not just the answer.

FTO Alg Finder is a desktop solver for building and testing practical Face-Turning Octahedron algorithms. It supports graphical input, setup strings, restricted movesets, saved solver instances, partial-position input, last-layer searching, and an alg combiner for trying intermediate sets without doing the boring bookkeeping by hand.

input

Click the puzzle

Set colors manually, swap pieces, twist corners, or use partial-position input from the viewer.

search

Control the moveset

Run auto or exact-depth searches with selected moves, banned moves, threads, and all-solution mode.

algs

Combine and cancel

Try ordered pairs and triples of intermediate algorithms with optional U-slot insertion.

System requirements

Table generation wants breathing room.

Minimum practical setup

  • 64-bit Windows or Linux desktop.
  • 8 GiB RAM for shallow and moderate searches.
  • At least 1.2 GiB available RAM for pruning and transition tables.
  • 2 GiB free disk space for dependencies, builds, and normal caches.

Recommended for heavier use

  • 5-10 GiB free disk space for several solver instances or pruning caches.
  • Multiple CPU cores when using the thread setting.
  • Rust Edition 2024 toolchain, Node.js 18+, and npm when building from source.
  • More memory for deep exact-depth CLI searches.
